# API reference

This reference is generated from the Python source and docstrings. It covers every
production module, including the hook entry points, shared utilities, and the
parsers and source-editing helpers used by `sync-type-hints`.

The command-line interfaces are the supported public interface for normal use.
Python objects beginning with an underscore are documented here for maintainers,
but should be treated as implementation details.
